GitHub Pages сейчас показывает файлы репозитория, а не собранную игру. Нужно один раз переключить источник публикации:

  2. Запустите публикацию: Run workflow.
  3. Подождите 2–3 минуты, пока появится зелёная галочка ✅, и обновите эту страницу.
